# Sollelio Brand Foundations — v0.1

This package converts the approved visual direction into deterministic SVG assets.

## Approved architecture

- Masterbrand: **Sollelio**
- First product: **Sollelio Events**
- Provisional second-product working name: **Sollelio Workforce**
- Product model: one unchanged master symbol, with one controlled product accent.

## Symbol logic

Four coordinated planes share one continuous negative-space route. The route subtly suggests an `S` without becoming a literal monogram. The symbol must never be redrawn per product.

## Typography

The editable lockups use **Rubik Regular** with fallbacks. Matching `-outlined.svg` files convert all typography to vector paths and are the preferred files for production publication. The master wordmark is dominant; product descriptors are subordinate.

## Usage rules

- Keep clear space around the logo equal to at least one quarter of the symbol width.
- Use the standalone symbol below approximately 140 px total lockup width.
- At 32 px, use the symbol only.
- Do not add gradients, shadows, glow, outlines or 3D effects.
- Do not rotate, stretch, rearrange or independently recolour the four planes.
- Product differentiation changes only the top-right accent plane.
- `Workforce` remains provisional until product naming is completed.
