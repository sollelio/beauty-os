# Sollelio Beauty OS — Brand Assets v0.1

This package implements the approved **Precision Violet** direction as a responsive extension of the Sollelio masterbrand.

## Brand architecture

- **Sollelio** — masterbrand
- **Sollelio Beauty OS** — product
- **Salão Agradável and other businesses** — tenants inside the product

Beauty OS does not receive an independent symbol. The Sollelio mark remains structurally unchanged; only the top-right accent plane changes.

## Usage

- Use the full `Sollelio / Beauty OS` lockup for websites, proposals and public commercial materials.
- Use the compact `Beauty OS / SOLLELIO` lockup only where the Sollelio product context is already established.
- Use the isolated symbol for favicon, PWA and app icons.
- Use the supplied splash compositions as references; splash must remain short and non-blocking.
- Tenant names and logos belong inside the authenticated product experience, never inside the Beauty OS logo.
- Do not rotate, redraw, rearrange, stretch, outline or independently recolour the symbol.
- Do not add gradients, shadows, salon imagery, beauty clichés or a `B`/`BOS` monogram.

## Production note

Editable lockups use Rubik. Matching `-outlined.svg` files contain typography converted to vector paths and are preferred for production use.
